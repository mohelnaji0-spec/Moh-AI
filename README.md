# 🤖 Moh AI

مساعد ذكي يعمل بالذكاء الاصطناعي، مبني على تقنية **Groq API** ونموذج **Llama 3.3 70B**، مع واجهة مستخدم أنيقة وسهلة الاستخدام. تم تصميمه ليكون بديلاً بسيطاً وسريعاً لـ ChatGPT.

![Moh AI Screenshot](https://via.placeholder.com/800x400?text=Moh+AI+Chat+Interface)

---

## ✨ المميزات

- ⚡ **سرعة فائقة**: بفضل معالجات Groq السريعة.
- 🎨 **واجهة مستخدم عصرية**: تصميم جذاب باللغة العربية مع وضع مظلم.
- 🔒 **آمن**: المفتاح الخاص محفوظ في متغيرات البيئة وليس في الكود.
- 🌐 **جاهز للنشر على Vercel**: يعمل كـ Serverless Functions.
- 🛡️ **معالجة ذكية للأخطاء**: لن تتوقف عند حالة "جاري..." بل تظهر رسائل خطأ واضحة.
- 📱 **متجاوب مع جميع الأجهزة**: يعمل على الهواتف والأجهزة اللوحية والحواسيب.

---

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
| :--- | :--- |
| **HTML + CSS + JavaScript** | الواجهة الأمامية |
| **Node.js + Express** | الخادم الخلفي (لتطوير محلي) |
| **Groq SDK** | الاتصال بـ Groq API |
| **Vercel** | النشر والاستضافة (Serverless Functions) |
| **Llama 3.3 70B** | نموذج الذكاء الاصطناعي |
